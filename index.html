¿Cómo se calcula el progreso?

Cuenta 1 issue: el issue está asignado a tu usuario, está cerrado y se encuentra una referencia de cierre estándar en un PR fusionado del mismo repositorio (por ejemplo, Fixes #123, Closes #123 o Resolves #123).

No suma todavía: issues abiertos, PRs abiertos o issues cerrados para los que no se pudo verificar un PR fusionado mediante esa referencia.

GitHub puede cerrar un issue mediante referencias incluidas en la descripción o título del PR. Si el PR no contiene una referencia de cierre reconocible, aparecerá como “Cerrado sin PR verificado” y no se contará automáticamente.
