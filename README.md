
# 🚀 CONT ISSUES

Página web para consultar y dar seguimiento a issues de GitHub, con una interfaz sencilla y organizada.

## 🌐 Acceso a la página

🔗 [**Entrar a CONT ISSUES**](https://denpimen08-debug.github.io/cont-issues/)

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## 📋 Características

- Visualización de información relacionada con issues.
- Interfaz organizada y adaptable a diferentes dispositivos.
- Diseño con temática tecnológica.

## 💻 Instalación y uso

### 1. Clonar el repositorio

```bash
git clone https://github.com/denpimen08-debug/cont-issues.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd cont-issues
```

### 3. Ejecutar la página

Abre el archivo `index.html` en tu navegador web para utilizar la página.

También puedes abrir la carpeta del proyecto con Visual Studio Code y utilizar la extensión Live Server.
